# No mandatory cost operating guardrails

PanganLens is designed so the portfolio deployment does not require a paid hosting plan or a continuously running application server.

## Website

The public website is static HTML, CSS, JavaScript, and a generated JSON snapshot. It is intended for a public GitHub repository using GitHub Pages. The browser never connects to BigQuery and never receives Google Cloud credentials.

## BigQuery

BigQuery is still a metered cloud service. PanganLens therefore treats zero-cost operation as a usage target with explicit limits, not as a promise that Google Cloud can never generate a charge.

For the portfolio-sized dataset:

- Keep total BigQuery storage below the current free-tier allowance.
- Use on-demand query pricing only. Do not create slot reservations or BI Engine reservations.
- Keep dashboard snapshot refresh manual until production WIF and mapping gates are complete.
- The website snapshot exporter sets `maximum_bytes_billed` for every query and reads curated mart views only.
- The public browser never runs BigQuery queries, so visitor traffic does not multiply warehouse query cost.
- Prefer one controlled snapshot refresh after a successful pipeline publish instead of querying BigQuery on every page view.
- Review Google Cloud billing and usage before enabling any recurring production schedule.

If free-tier usage would be exceeded, the correct action for this portfolio deployment is to stop or reduce refresh frequency rather than silently accept a charge.

## Looker Studio

The user-owned Looker Studio report may connect to the curated BigQuery views. BigQuery usage generated by that report counts toward the same Google Cloud usage limits, so report refreshes and exploratory queries should remain modest while the project is operated as a no-mandatory-cost portfolio.

## Production gate

A recurring refresh must not be enabled until all of these are true:

1. Workload Identity Federation smoke test is green.
2. Reviewed mappings are populated and production ingestion is green.
3. BigQuery storage and monthly query usage are comfortably inside the free tier.
4. The website snapshot query stays below its configured bytes-billed ceiling.
5. The operator has reviewed current Google Cloud pricing and billing configuration.
